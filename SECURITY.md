# Security Policy

## Supported branch

Security fixes are applied to the current `main` branch of this public reference implementation.

## Reporting

Do not open a public issue for a suspected vulnerability. Use GitHub private vulnerability reporting for this repository. Include the affected route or component, reproduction steps, impact, and any suggested mitigation.

Do not include real credentials, customer data, private infrastructure details, or proprietary source material in a report.

## Scope

This repository uses deterministic synthetic data and public-safe abstractions. It is not a production deployment. Reports about exposed secrets, authentication bypass, command authorization, data-integrity controls, dependency handling, or unsafe defaults are still in scope because they affect the quality of the reference implementation.
